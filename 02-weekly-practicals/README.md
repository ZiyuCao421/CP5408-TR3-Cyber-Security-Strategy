# CP5408 Weekly Practicals

GitHub-ready study record for **Cyber Security Strategy Governance and Risk Management**. The repository treats the practicals as one continuous applied study: DJI is the fixed organisation prototype, and every weekly task extends, tests, or operationalises the analysis from the preceding week.

## Continuous case progression

```text
Week 1  Organisation scope, assets, CIA/MSR
   ↓
Week 2  Risk statements, register, ratings, owners, treatments
   ↓
Week 3  Quantified scenarios, ALE, residual risk, cost-benefit assumptions
   ↓
Week 4  Evidence quality, data scales, confidence, ranges, visual checks
   ↓
Week 5  Data decisions, objectives, KPIs, initiatives, three-year roadmap
   ↓
Weeks 6–10  Continue the same DJI case with the prior register, assumptions, evidence log, and roadmap as working inputs
```

## Structure

Each weekly page follows the same three-part format:

1. **Completed weekly practical** — submitted tables or reproducible notebook work.
2. **Weekly reflection** — learning, judgement, and an identified evidence limitation.
3. **Related case studies** — repository-relative links for GitHub navigation.

Weeks 6–10 are pre-created as empty, consistently formatted workspaces. When the next worksheet is available, its completed work will be added without changing the accumulated DJI case context.

## Publishing on GitHub

1. Create an empty GitHub repository, then upload this folder's contents.
2. Keep the folder names unchanged so all relative links continue to work.
3. Open this `README.md` on GitHub; the table above acts as the course home page.

## Academic integrity and evidence

This portfolio preserves the submitted coursework analysis. It clearly labels scenario assumptions, synthetic data, and public context so that they are not presented as verified DJI internal facts. Add formal references or instructor-required citations before using any section in an assessed submission.
