# CP5408 — Cyber Security Strategy, Governance and Risk Management

This repository is a structured knowledge base for CP5408 coursework. It separates assessment deliverables, weekly practical work, and case studies so that learning artefacts remain easy to browse, trace, and extend.

## Repository map

| Area | Purpose |
| --- | --- |
| [`01-assessments`](01-assessments/) | Final assessment deliverables and supporting analysis. |
| [`02-weekly-practicals`](02-weekly-practicals/) | Ten weeks of practical notes, notebooks, data, and reflections. |
| [`03-case-studies`](03-case-studies/) | Independent case-study analyses and reusable research notes. |
| [`04-resources`](04-resources/) | Reusable frameworks, templates, and reference material. |

## Current material

- **Assessment 1 — DJI:** completed report and risk-analysis notebook.
- **Week 3:** DJI practical notebook.
- **Week 5:** aligned and student practical notebooks plus the assumptions log.

The remaining directories intentionally contain short index pages only; add original course artefacts there as they become available. This keeps a clear boundary between submitted work and future study notes.

## Conventions

- Use `week-01` through `week-10` for practical material.
- Put a brief `README.md` in each topic folder explaining its purpose and sources.
- Keep assessment artefacts inside their assessment folder; cross-link to the relevant weekly work instead of duplicating files.
- Clearly label assumptions, synthetic teaching data, and publicly sourced evidence.

## Academic note

This is an academic knowledge base. Case-study analysis and numerical estimates are learning artefacts, not statements of an organisation's actual security posture, internal data, or commitments.
